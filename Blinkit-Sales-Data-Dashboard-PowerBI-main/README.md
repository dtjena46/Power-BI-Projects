### Blinkit Grocery Sales Analysis Dashboard | Power BI

Developed an interactive Power BI dashboard to analyse Blinkit's grocery sales performance across outlet types, outlet sizes, item categories, and fat content.

**Key Features:**
- KPI tracking for Total Sales, Average Sales, Number of Items, and Average Rating.
- Sales trend analysis by outlet establishment year.
- Outlet performance comparison by location tier, size, and type.
- Interactive filters for outlet location type, outlet size, and item type.

**Tools:** Power BI, DAX, Data Visualisation, Interactive Reporting.

**Objective:** To identify sales trends, compare outlet performance, and support data-driven business decisions.
