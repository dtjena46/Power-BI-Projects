# Asha Foundation – NGO Impact & Fund Utilisation Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyse the social impact, beneficiary reach, programme performance, and fund utilisation of Asha Foundation.

The dashboard provides insights into NGO activities across six Indian states, helping stakeholders understand beneficiary trends, programme effectiveness, and resource utilisation.

## Objectives

- Analyse beneficiary distribution and growth over time.
- Monitor fund allocation, expenditure, and utilisation.
- Evaluate programme-level impact and operational efficiency.
- Compare beneficiary performance across years and quarters.
- Analyse performance across programme categories and Sustainable Development Goals (SDGs).
- Present key performance indicators through an interactive dashboard.

## Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualisation.
- **DAX** – Measures, calculations, and performance indicators.
- **Power Query** – Data preparation and transformation, where applicable.
- **CSV** – Source datasets.
- **Data Modelling** – Connecting datasets for analysis.

## Dataset Files

| File | Purpose |
|---|---|
| `date_dimension_dataset.csv` | Date-related analysis and time intelligence |
| `ngo_programme_dataset.csv` | NGO programme information and related analysis |
| `officers_dataset.csv` | Officer-related information |
| `programme_types_dataset.csv` | Programme classification |
| `states_dataset.csv` | State-level information |
| `AshaFoundation_Impact_Dashboard.pbix` | Power BI dashboard project |

## Dashboard Features

### 1. Impact Efficiency
Analyses programme-level impact efficiency across initiatives such as vocational training, maternal health support, digital literacy, and education.

### 2. Year-over-Year Beneficiary Comparison
Visualises quarterly beneficiary trends and compares performance across reporting years.

### 3. Programme and SDG Analysis
Provides a tabular breakdown of programme-related indicators and beneficiary totals associated with Sustainable Development Goals.

### 4. Programme Category Analysis
Displays key categories such as Education, Environment, Healthcare, Legal, and Livelihood.

### 5. NGO Overview
Highlights the foundation's presence across six states, beneficiary reach, active programmes, and reporting indicators.

2. Open `AshaFoundation_Impact_Dashboard.pbix` using Microsoft Power BI Desktop.
3. If prompted, update the data source paths to match the downloaded CSV files.
